## Проект предоставляет функции для фильтрации и сортировки банковских операций.

## Установка:

1. Клонируйте репозиторий:
'''
https://github.com/abdlovd/PythonProject3/tree/Develop
'''

2. Установите зависимости:
'''
pip install -r requirements.txt


3. В проект добавлен новый модуль generators, который содержит функции-генераторы для обработки данных. Генераторы позволяют получать значения по одному, что делает работу с большими наборами данных более эффективной и экономичной по памяти.

Функция filter_by_currency предназначена для фильтрации списка транзакций. Она принимает набор операций и заданную валюту и последовательно возвращает только те транзакции, в которых валюта операции соответствует указанной. Это упрощает анализ финансовых данных и выборку нужных операций.

Генератор transaction_descriptions используется для поочерёдного получения текстовых описаний транзакций. Он принимает список операций и формирует удобочитаемое описание каждой из них, не создавая дополнительный список в памяти.

Генератор card_number_generator служит для последовательной генерации номеров банковских карт в установленном формате. Он принимает начальное и конечное значения диапазона и возвращает номера карт по одному, что удобно для тестирования и демонстрации работы с генераторами.

Для всех новых функций реализованы тесты, обеспечивающие достаточное покрытие кода и корректность работы модуля. 


4. Новая функциональность. В проект была добавлена поддержка загрузки и обработки финансовых транзакций из различных источников и валют.

а) Загрузка транзакций

Реализованы функции для чтения финансовых операций из файлов следующих форматов:

JSON

CSV

XLSX

Все функции возвращают список словарей с данными о транзакциях.
В случае ошибки чтения файла или некорректного формата возвращается пустой список.

Файлы с транзакциями размещаются в директории:

data/

б) Конвертация валют

Добавлена поддержка автоматической конвертации сумм транзакций в рубли (RUB):

USD → RUB

EUR → RUB

Для получения актуальных курсов валют используется Exchange Rates Data API.
API-ключ хранится в переменных окружения и не попадает в репозиторий.

в) Переменные окружения

Для работы с внешним API используется файл .env.

Пример шаблона .env:

EXCHANGE_API_KEY=your_api_key_here

г) Тестирование

Для новых функций реализованы unit-тесты с использованием:

unittest.mock

patch

Это позволяет тестировать код без реальных запросов к внешнему API.
